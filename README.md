# Rede Climática Comunitária de Porto Velho

Apresentação institucional e técnica do projeto de uma rede comunitária de estações meteorológicas, sensores IoT de baixo custo e conectividade LoRa/MeshCore em Porto Velho e região.

## Publicação

O site é estático e pode ser publicado diretamente pelo GitHub Pages. O workflow em `.github/workflows/pages.yml` publica o conteúdo do repositório sempre que houver alteração na branch `main`.

## Uso local

Abra `index.html` em um navegador ou use um servidor estático:

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`.

## Navegação

- Setas esquerda/direita, `PageUp` e `PageDown`: navegar.
- Espaço: próximo slide.
- `Home` e `End`: primeiro e último slide.
- `F`: tela cheia.
- Toque lateral: navegar no celular.

## Segurança

Este repositório não deve conter IPs privados, senhas, tokens Tailscale, arquivos `.env`, chaves de autenticação ou estados de daemon. Os nomes `verde008` e `verde009` aparecem somente como identificação lógica dos servidores comunitários.

## Conteúdo do projeto

O roadmap cobre 2026 a 2028 e separa infraestrutura já ativa de itens planejados. A apresentação inclui um mapa real de Porto Velho com pontos propostos, além de slides específicos sobre os ganhos para universidades e para a agricultura familiar, pequena e média produção. A participação de IFRO, hackerspaces, comunidades técnicas, grupos de pesquisa, cooperativas, empresas e órgãos públicos é apresentada como oportunidade de cooperação, não como parceria já formalizada.
